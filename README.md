# 亚当夏娃 · 策略 V2

A 股日线形态扫描与研究回测。支持亚当夏娃（先尖底后圆底）和夏娃启V（先圆底后尖底）。V2 修复了历史信号的时间顺序与持仓净值计算，并加入风险仓位与趋势退出对照。参数是明确的研究假设，尚未证明提高样本外收益。

## 信号与执行

- 历史信号逐日读取最多220根已知日线；只有当时能确认的形态才记录，评分在首次确认时冻结，不再用后来回踩重新选取或替换。
- 突破后的3根日线内允许完成右侧低点确认；信号日可能晚于突破日，不能把两者混作同一天。
- 信号收盘确认，下一交易日开盘尝试成交。开盘已低于止损、开在涨停附近、风险距离超过20%，或固定退出版本开盘已达到目标，放弃交易。
- 组合要求成交日等于指数日历里的下一交易日；停牌后迟来的开盘不追认成交。
- T+1：买入当天不卖。跌停封死或无成交时不假设能止损，退出请求保留至可成交日；跳空越过止损按开盘价处理。
- 原始形态目标仍用于图表参考和固定退出对照。候选扫描可含构筑形态，不等于已确认入场信号。

## 仓位与退出

每筆初始计划风险为净值的0.5%，预算包含止损距离及估计往返费用；每只仓位不超过12.5%，同时最多8笔。跳空、停牌等可能使实际损失超过计划风险。

弱市定义保留：上证或沪深300低于20日线3%以上，且均线下降。使用信号日信息限制新开仓：评分至少76、每日最多1笔、已有持仓达到3笔则不再开仓。**不强制将旧仓减至3笔。**

| 退出版本         | 规则                                                                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 趋势退出（默认） | 初始止损在两底较低者下方1%；随后以持仓最高价减3倍ATR上移止损，只收紧、不放宽，当日计算从下一日生效；持有120根日线后于可成交日开盘退出 |
| 固定退出（对照） | 原形态目标与初始止损，持有30根日线后于可成交日开盘退出；同日目标与止损都触及，保守按止损处理                                          |

这两组使用相同的因果信号和风险预算；退出时间不同会改变后续可用仓位，因此组合成交笔数可以不同。对照结果不等于旧版回测。

## 净值与费用

- 每个交易日按收盘市价估值，最大回撤包含持仓浮亏；期末未平仓不虚构卖出，净值包含其市值。
- 胜率、盈亏比、笔均收益只统计已平仓交易。
- 当天开仓不提前使用当天稍后退出所得资金；仓位预算使用上一日净值。
- 买入佣金0.025%、卖出佣金0.025%及印花税0.05%，单边滑点0.1%。历史费率未逐年还原。
- 使用连续仓位比例，未模拟整手数量、最低佣金和盘口容量。

## 行情与运行方式

新浪提供按当前成交额排序的股票名单；腾讯提供前复权日线以及用于估算名义成交额的未复权日线，无需Tushare Token。

批量扫描每只约170根日线，单票和短期回测640根。原版扫描前60/100只，逆向扫描前800/1600只；组合回测分别取当前约200/500只。均过滤当前名称中的ST、退市等标识及近20日平均成交额不足8000万元的股票。

- 只使用已完成日线：北京时间16:00之前剔除当天K线。页面首次加载和手动操作触发扫描，没有持续实时行情推送。
- K线进程内缓存8分钟；手动扫描绕过缓存。回测结果缓存30分钟，“重新计算”绕过回测与个股缓存。
- 回测改为按钮显式触发，避免打开页面即启动大批历史请求。
- 成交额用未复权收盘价×成交量估算，并非精确逐笔成交额；不再使用前复权价格或猜测腾讯数组第9项单位。
- 不把未经统一复权的新浪备用日线静默混入；腾讯不可用时明确报错。
- 二十年数据分段取回：请求失败会报错，跨分段的复权不一致会拒绝该股票；部分股票失败会显示排除数量与示例原因。
- 移除硬编码`/workspace/.cache`长期报告读写。旧缓存不再读取，避免Vercel运行时写文件和永久过期报告问题。

## 结果边界

旧版“近两年+110%”“二十年+211%”等数字不适用于V2，已撤下。只有实际重跑才能生成新版本结果。

**仍是当前股票池的历史重放，不能宣称历史全市场回测或消除了幸存者偏差。** 缺少历史退市名单、历史ST状态及完整特殊涨跌停规则。停牌期间估值沿用最近报价；数据缺失仍可能影响估值。没有样本外证据证明3 ATR、0.5%或120日是最优参数。

下一轮研究：同股票池的简单突破基准、滚动样本外验证，以及收益集中度。没有新增资金实盘或自动下单功能。

```bash
npm run dev
```

`npm test`还包含Grok模板原有测试。策略测试使用确定性样本与隔离的行情响应，不依赖在线行情。

核心代码：`src/lib/pattern/adam-eve.ts`（信号与单票执行）、`src/lib/market/strategy.ts`（组合与每日净值）、`strategy-run.ts`（回测编排）、`quotes.ts`（行情）、`scripts/strategy-engine.test.mjs`（回归测试）。
