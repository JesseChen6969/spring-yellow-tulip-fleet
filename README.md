# 亚当夏娃

A 股日线形态扫描。两套规则分开跑，不是同一个开关。

页面上可以看当前形态、单只股票以前出现过的机会，以及按同一套进出场规则复利出来的组合收益。行情用前复权日线。这不是交易建议，回测数字不能当成以后的收益。

## 两套策略

### 亚当夏娃

高位跌下来之后的第二波。先是一根尖底（亚当），再是一个圆底（夏娃），然后收盘站上两底之间的颈线。

- 止损放在两个底的较低者下方 1%。
- 目标是颈线加上形态高度，也就是颈线减去底部的那段距离，再加回去。
- 股票池按近期成交额从高到低取。

### 夏娃启V

底部区间里的反向版本，单独展示。先在低位磨出一个圆底（夏娃），再用很少几根 K 线拉出尖底（亚当），收盘冲过区间高点。慢吞吞磨上去的不算。

底部股票进不了成交额前列，所以这套不按当日成交额前 100 取，而是往更长的流动性名单里扫，再用下面的 8000 万过滤。

- 止损同样在两个底的较低者下方 1%。
- 目标不按浅底的那一点高度。取「这段跌幅的一半」和「从突破价量出的一倍止损」里更远的一个。如果更远的那个已经超过跌下来之前的高点，就停在前高，除非一倍止损本身已经越过前高。
- 盈亏比按突破当天的收盘价算，不按你现在看到的价格。现价离目标已经近于离止损的，标成延伸，不进可交易。

## 什么股票能进

1. 去掉 ST、*ST、退市整理，以及名字以 N、C 开头的次新标识。
2. 上市不满 60 个交易日的去掉。
3. 近 20 个交易日日均成交额低于 8000 万元的去掉。
4. 停牌、当天没有成交、当天一字涨停买不进的去掉。主板按 10% 涨跌停，创业板和科创板按 20%。
5. 上证指数或沪深 300 收在 20 日均线下方超过 3%，而且均线还在向下时，少做。平时最多 8 笔，每笔用当时权益的 12.5%。这种弱市最多 3 笔，当天只新开 1 笔，评分至少 76。

## 一笔交易怎么结算

突破日收盘价进场。之后 30 个交易日里，先碰到目标还是先碰到止损。同一根 K 线都碰到，记为止损。30 天都没碰到，按到期那根的收盘价离场。

费用按这一档估：买入佣金 0.025% 加滑点 0.1%，卖出再加印花税 0.05% 和同样的佣金、滑点。

## 回测里看到过的数

样本是现在还有成交的股票，退市的不在里面。8000 万按当时的名义成交额卡，早年很多信号过不了。下面是逆向这套曾经跑出来的结果，不是承诺。

| | 近两年多 | 2006-09-25 至 2026-09-23 |
|---|---|---|
| 组合收益 | +110% | +211% |
| 年化 | +32% | +5.8% |
| 最大回撤 | -9.9% | -17.8% |
| 胜率 | 62% | 53% |
| 盈亏比 | 1.38 | 1.24 |
| 笔均净收益 | +4.3% | +1.9% |

二十年里第一笔实际成交在 2009-08-04。净值不是匀速涨的：2009 到 2014 几乎没赚，2019 以及 2024 到 2026 占了大部分。近两年的高年化，是底部突破撞上了一段从跌转涨，不是这套规则每年都有的水平。弱市过滤在这二十年里只挡掉很少的笔。

## 代码在哪

| 文件 | 内容 |
|---|---|
| `src/lib/pattern/adam-eve.ts` | 两套形态、止损、目标、单只历史机会。`collectPatterns` 是亚当夏娃，`collectEveAdam` 是夏娃启V。 |
| `src/lib/market/gates.ts` | ST、次新、成交额、一字涨停、弱市。 |
| `src/lib/market/strategy.ts` | 仓位、扣费、净值、年化、回撤。 |
| `src/lib/market/strategy-run.ts` | 组合回测。逆向可以拉到 2006 年 9 月，日线是分段拼出来的。 |
| `src/lib/market/quotes.ts` | 股票列表和日线。 |
| `src/lib/market/scan.ts` | 当前扫描，接到页面上。 |
| `src/components/terminal/terminal.tsx` | 页面。 |
